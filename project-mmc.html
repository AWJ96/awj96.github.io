Steady-State Analysis Tool for Modular Multilevel Converters in VSC-HVDC Systems (On‑going)

Status: On-going

Institution: Imperial College London
Supervisor: Dr. Adria Junyent‑Ferre
Tools & Techniques: MATLAB, GUI Development, Converter Modeling, Signal Processing, Power Electronics
Timeline: Jan 2025–Present

This project develops a MATLAB-based tool for the steady-state analysis of Modular Multilevel Converters (MMCs) used in Voltage Source Converter–High Voltage Direct Current (VSC-HVDC) systems. The tool lets users configure converter parameters and visualize internal dynamics such as arm currents, capacitor voltage ripple, and submodule energy. It also computes feasible active/reactive power boundaries (P–Q) to support controller design and operating-point validation.

Key Contributions

  • Designed and implemented a GUI-based MATLAB tool for steady-state MMC analysis.
  • Modeled internal converter behavior including submodule capacitance, circulating currents, and power exchange.
  • Enabled parametric sensitivity studies (e.g., AC-side filter impedance, submodule capacitance).
  • Visualized converter P–Q operating regions for feasibility assessment.
  • Established a foundation for future transient and fault-response analysis.

Methodology

This section summarizes how the tool computes steady-state behaviour and the P–Q operating boundary, matching the MATLAB implementation and thesis model.

  1. GUI & State Management. A persistent handles struct stores UI references and computed data. Debounced callbacks (realTimeUpdate, updateInterval) prevent thrashing during slider drags. Config Save/Load uses MAT files for reproducibility.
  2. Safe-Zone Computation. After any parameter change, updateAllSafeZones recomputes admissible ranges:
    • Voltage headroom: Vac ≤ m·Vdc·√(3/8), Vdc ≥ Vac·√(8/3)/m (with m=1).
    • Fixed-nameplate circle: P²+Q² ≤ |S|².
    • Grid current hint: I_limit = |S|/(√3·Vac) and filter headroom heuristic to set a safe slider band.
    • Component heuristics for N, Csm, Larm, Rfilt, Lfilt (loss/voltage-drop bounds).
  3. Waveform Synthesis. AC side phasors reconstruct PCC voltages/currents from (P,Q) and filter (R,L). Internal arm waveforms use ideal modulation with arm inductance derivatives applied to voltage equations.
  4. Capacitor Model. Per-arm energy integration (E += P·Δt) maps to equivalent SM voltage V = √(2E/(C·N)). Optional drift injects a small bias to visualize long-term imbalance.
  5. P–Q Capability Boundary. For angles θ∈[0°,360°], the solver increases |S| until either converter voltage or current limit is hit, with bisection refinement. Segments are tagged V-limited (magenta) or C-limited (red). Exportable preview and Excel writer reproduce tables/plots.
  6. Validation. Reference test cases reproduce literature/benchmark behaviours (grid-side magnitudes, arm quantities, boundary shape) under stated assumptions.
