Steady‑State Analysis Tool for Modular Multilevel Converters in VSC‑HVDC Systems (On‑going)

Institution: Imperial College London
Supervisor: Dr. Adria Junyent‑Ferre
Tools & Techniques: MATLAB, GUI Development, Converter Modeling, Signal Processing, Power Electronics

This project develops a MATLAB‑based tool for the steady‑state analysis of Modular Multilevel Converters (MMCs) used in Voltage Source Converter–High Voltage Direct Current (VSC‑HVDC) systems. The tool configures converter parameters and visualizes arm currents, capacitor‑voltage ripple, and submodule energy, and computes feasible P–Q operating boundaries for controller design and operating‑point validation.

Key Contributions

  • GUI‑based MATLAB tool for steady‑state MMC analysis
  • Internal behavior modeling: submodule capacitance, circulating currents, power exchange
  • Parametric sensitivity analysis (AC filter impedance, SM capacitance)
  • P–Q operating region visualization with breach tagging
  • Foundation for future transient and fault‑response analysis

Methodology

The solver enforces fixed‑MVA nameplate limits and evaluates voltage/current feasibility per operating angle. After any parameter edit, safe zones are recomputed and the waveforms & P–Q plane refresh in real time.

  • Limits: Vac ≤ m·Vdc·√(3/8), Vdc ≥ Vac·√(8/3)/m (m=1), and fixed circle P²+Q² ≤ |S|².
  • Boundary search: θ∈[0°,360°]에서 |S|을 증가시키며 전압/전류 한계 충돌 시점을 이분법으로 정밀화, V‑제한(자홍)/C‑제한(적색) 구간 태깅.
  • Waveforms: 필터(R,L) 포함한 PCC 전압·전류 합성, 팔 전류/전압 및 능동전력 계산.
  • SM 커패시터: E += P·Δt, V = √(2E/(C·N)); 드리프트 옵션으로 장기 불평형 시각화.
